# Product definition

## Product category

Soma is a local-first desktop application.

## Users

Soma is for people who use AI conversations for substantial work. These users include
builders, researchers, designers, engineers, founders, and operators.

They need to change old conversations into reusable structure. A chronological chat
history does not give this structure.

## Purpose

Soma changes imported conversations into an evidence-backed graph of compiled
conversation sections.

Users can:

- import source conversations
- read complete node bodies
- ask questions about one node or the full graph
- read and question a PDF
- review proposed graph changes
- find old ideas

## Brand character

Soma is quiet, rigorous, and active.

## Visual exclusions

Do not make Soma look like these products:

- a generic software dashboard
- a colorful mind map
- a purple or blue AI assistant
- an Obsidian copy
- a nested-card productivity template
- a chatbot that uses a mascot

Do not use decorative gradients, chat bubbles as identity, noisy motion, or default
generated-interface typography.

## Design principles

1. Structure is the interface. Use the graph, documents, evidence, and chat to make
   thought navigable.
2. Trust is more important than automation. Keep proposed changes, evidence, and
   version history visible.
3. Use precise alignment, contrast, spacing, and typography. Do not use unnecessary
   decoration.
4. Make node detail a readable document. Do not make it a metadata card.
5. Use motion to show state. Do not move trusted graph positions without a user action.

## Accessibility

Meet WCAG AA contrast requirements. Keep keyboard focus visible. Use readable body
text and `rem` units.

Support reduced motion and interface zoom. Do not use color as the only indication of
important state.
